# MB16 MVP scope

## Входит
- Telegram Mini App
- 1 роль клиента + список admin Telegram IDs
- карточка товара: 3–5 фото, optional video, название, описание, артикул, категория, цена, цвета, размеры
- простой каталог
- выбор цвет + размер
- одна подборка
- запрос даты и времени примерки
- ручная проверка наличия админом
- подтверждение/изменение времени
- отметка клиента о покупке
- подтверждение продажи админом
- история покупок клиента

## Не входит сейчас
- онлайн-оплата
- автоматический склад / количественные остатки по SKU
- CRM
- персональные менеджеры
- AI-рекомендации и подбор образов
- аналитические дашборды
- программа лояльности
- промокоды
- доставка
- мульти-шоурум

Все эти модули можно добавлять позже отдельными сервисами/таблицами, не меняя текущий основной flow.
